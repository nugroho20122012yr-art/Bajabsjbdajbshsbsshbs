Web2APK Gratis 100%

Website kamu jadi aplikasi Android, gratis.

Isi form, tunggu beberapa menit, lalu unduh APK-nya. Tanpa akun, tanpa token, tanpa biaya.

Bisa dari link website, kode HTML, atau file ZIP. Kamu juga bisa mengunci orientasi layar dan memilih izin yang dibutuhkan aplikasi.

  1. 1Isi form di bawah dan tekan tombol buat.
  2. 2APK dibuat otomatis di GitHub. Tunggu sampai selesai.
  3. 3Unduh APK, lalu pasang di HP.

Buat APK

Aplikasi

Nama muncul di bawah ikon aplikasi. Package name adalah identitas unik aplikasi di Android.

Ikon

Gambar apa saja (PNG, JPG, WebP). Dipotong persegi otomatis. Kosongkan untuk memakai ikon bawaan.

Bawaan

Isi aplikasi

Pilih dari mana aplikasi mengambil isinya.

Harus diawali https://. Aplikasi akan membuka website ini di dalamnya.

Satu file HTML saja. CSS dan JavaScript tulis langsung di dalamnya.

ZIP harus punya index.html (di dalam folder pun boleh). Maksimal 3 MB per file dan 25 MB total.

Orientasi layar

Atur bagaimana layar aplikasi berputar.

Izin aplikasi

Centang hanya yang dibutuhkan. Semakin sedikit izin, semakin mudah pengguna percaya.

InternetStatus jaringan selalu aktif.

    Unduh APK

    Saat memasang, Android akan meminta izin memasang dari sumber yang tidak dikenal. Izinkan untuk browser yang kamu pakai.

    Simpan nama repo di atas. Kalau halaman ini ditutup, APK tetap bisa diambil di tab Releases pada repo itu.

    Web2APK membuat APK debug lewat GitHub Actions. Cocok untuk pemakaian pribadi dan uji coba.
